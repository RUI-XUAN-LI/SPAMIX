# Behind the Blocklist: Understanding and Evaluating Email Infrastructure Reputation from an Industry Perspective

- **spamix_score.csv** contains the anomaly scores and feature values for SPAMIX entries with a sending volume greater than 500 during the period from 2025-01-01 to 2025-08-01.
- **feature_weight** contains the code that uses the logistic regression algorithm to generate feature weights.
- **SPAMIX_build** contains the code for calculating anomaly scores using SPMIX.
